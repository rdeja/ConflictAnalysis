# ConflictAnalysis
Following the paper it allows conflict analysis using Pareto optimal approach.

## Overview
This module implements a general computational framework for conflict analysis using a Pareto-based multi-objective evaluation strategy. Its main purpose is to compare alternative scenarios or parameter configurations across multiple criteria and identify non-dominated solutions.

The usage of the library is presented using popular Middle east conflict situation. The details are described within each file:
- pareto_conf_general.py is the source code of the library
- middle_east_experiments.ipynb presents how to use this library
